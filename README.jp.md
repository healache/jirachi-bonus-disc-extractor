# ジラーチ配布ディスク抽出ツール

[English](README.md) | 日本語

2003年の米国版ポケモンコロシアム予約特典ディスク（`PC6E01 Rev.00`）から、3種類の
ジラーチ配布ROMを抽出する。HTMLファイル1つでオフライン動作。

## 使い方

<https://healache.github.io/jirachi-bonus-disc-extractor/> を開く。

1. `PC6E01.iso` をドロップする。
2. 出力形式を選ぶ。マルチブートROMは実機およびmGBAなどマルチブート対応
   エミュレータ向け。エミュレータ互換ROMはマルチブートROMを正しく読み込めない
   GBAエミュレータ向け。
3. ROMをダウンロードする。

## 収録ROM

| ファイル               | おや       | TID   | 言語 | 区分     |
| ---------------------- | ---------- | ----- | ---- | -------- |
| `client.bin`           | WISHMKR    | 20043 | ENG  | 公式配布 |
| `client.2003_1112.bin` | METEOR     | 30719 | ENG  | 未公開   |
| `sample0519.bin`       | ネガイボシ | 30719 | JPN  | 公式配布 |

## 色違い

WISHMKRとMETEORは色違いロックが壊れており、実機での厳選が可能。ネガイボシの
ロックは正常なため、解除パッチが必要。

| ROM                  | 確率        | 約        |
| -------------------- | ----------- | --------- |
| WISHMKR              | 9 / 65,536  | 1 / 7,282 |
| METEOR               | 10 / 65,536 | 1 / 6,554 |
| ネガイボシ（解除時） | 7 / 65,536  | 1 / 9,362 |

パッチは色違い判定の分岐をNOPに置き換える。

ネガイボシはGBAのRTCをシードに使い、セーブごとの引き換え回数制限もない。日本語版
を出自とする色違いジラーチを入手できる唯一の手段（WISHMKRとMETEORは英語版のみ）。

## サードパーティ
